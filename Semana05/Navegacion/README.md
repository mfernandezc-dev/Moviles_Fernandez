# Laboratorio Semana 05 - Navegación con Jetpack Compose

## Descripción del proyecto

Este proyecto corresponde al laboratorio de la Semana 05 del curso de Desarrollo de Aplicaciones Móviles.

El objetivo del laboratorio es implementar un sistema de navegación entre pantallas utilizando **Jetpack Compose Navigation**, aplicando rutas mediante una `sealed class`, un `NavHost`, un `NavController` y el envío de argumentos entre pantallas.

La aplicación permite navegar entre diferentes pantallas y manejar parámetros dinámicos mediante rutas.

---

# Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Navigation Compose
